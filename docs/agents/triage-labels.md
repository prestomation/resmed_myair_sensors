# Triage labels

Use the tracker value on the local issue’s `Status:` line when a skill calls for a triage role.

| Triage role | Tracker value | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | A maintainer needs to evaluate the issue |
| `needs-info` | `needs-info` | More information is needed from the reporter |
| `ready-for-agent` | `ready-for-agent` | The issue is specified and ready for an agent |
| `ready-for-human` | `ready-for-human` | The issue requires a human to implement it |
| `wontfix` | `wontfix` | The issue will be closed without implementation |
