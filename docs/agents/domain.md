# Domain docs

This repository uses one root `GLOSSARY.md` and one decision record directory at `docs/adr/`.

- Before exploring the codebase, read `GLOSSARY.md` and the ADRs relevant to your task. If either is absent, proceed silently. Add an entry or a decision record when a term or decision is settled.
- Use glossary terms in issue titles, proposals, hypotheses, and test names. If a needed term is missing, check the repository’s vocabulary before proposing a glossary entry.
- If a proposal conflicts with an ADR, cite the ADR and explain why the decision should be reopened.
